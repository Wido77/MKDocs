# Archivos

Deja aquí PDFs, dumps o texto que quieras servir con la web.

Ejemplo de enlace desde una nota:

```markdown
[Informe](informe.pdf)
```

Desde otra carpeta:

```markdown
[Informe](../archivos/informe.pdf)
```

Hay un `notes.txt` de ejemplo para comprobar que el archivo se copia al sitio.

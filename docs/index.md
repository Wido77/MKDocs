# Investigaciones

Cuaderno personal para guardar notas, comandos, capturas y archivos.

## Cómo usarlo

1. Crea una nota nueva en `docs/temas/`.
2. Añade comandos en bloques de código (botón de copiar incluido).
3. Guarda capturas en `docs/assets/images/` y enlázalas en la nota.
4. Deja PDFs u otros adjuntos en `docs/archivos/`.
5. Publica con `git push` a `main`; GitHub Pages construye el sitio solo.

## Estructura

| Carpeta | Para qué |
| --- | --- |
| `docs/temas/` | Investigaciones y apuntes |
| `docs/comandos/` | Cheatsheets reutilizables |
| `docs/archivos/` | PDFs, dumps, datasets pequeños |
| `docs/assets/images/` | Capturas de pantalla |
